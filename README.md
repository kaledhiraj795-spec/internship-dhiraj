# ASM NextGen Technical Campus

A responsive multi-page website for ASM NextGen Technical Campus.

## Run locally

Open `index.html` or `home.html` in a browser, or serve this directory with a local web server. All pages share the site navigation and link to their dedicated routes.

## Pages

- Home: `home.html`
- About: `about.html`
- Courses and programs: `coursesprog.html`
- Admissions: `addmission.html`
- Campus: `campus.html`
- Departments: `department.html`
- Faculty: `Faculty.html`
- Placements: `placement.html`
- Contact: `contact.html`

Page styles and scripts are in `css/` and `js/`. Shared images and JSON data are in `image/` and `data/`.
